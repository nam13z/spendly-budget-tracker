# Contributing to Spendly

Thank you for considering a contribution.

## Before contributing
Read:
- `AGENTS.md`
- `README.md`
- relevant product and architecture documents
- `docs/engineering/CODING_STANDARDS.md`
- `docs/engineering/TESTING_STRATEGY.md`

## Contribution principles
- Protect user privacy.
- Preserve financial correctness.
- Keep changes focused.
- Add tests for behavior.
- Document meaningful product/API changes.
- Discuss large changes before implementation.

## Reporting bugs
Include:
- expected behavior;
- actual behavior;
- reproduction steps;
- environment/version;
- screenshots/logs with sensitive information removed.

Never include real transaction data, passwords, tokens or account identifiers in public issues.

## Pull requests
Explain purpose, implementation, tests run, schema/API changes, security implications and known limitations.
